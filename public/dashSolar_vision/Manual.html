Manual de Instalação

Esse Manual foi criado para o auxilio dos suportes nivel 3 para a montagem e execução dos sensores.

O botão a seguir contém o mesmo conteudo do site mas em pdf, para melhor vizuaização.

!MATERIAIS UTILIZADOS!

1° -- 1 Arduíno Uno R3

2° -- 1 Protoboard

3° --

3 Jumpers

4°-- 1 Sensor LDR de Luminosidade

5° -- 1 Resistor




MONTAGEM DO ARDUINO


Passo 1 :

Conecte os jumpers no arduino nos encaixes 5v, GND e A0
( A cor dos fios que serão conectados não importa, apenas preze por serem cores diferentes para saber qual está conectado em qual)

Passo 2 :

Conecte o sensor a uma parte da protoboard

Passo 3 :

Conecte o Jumper que está no A0 na perna esquerda do sensor LDR

Passo 4 :

Conecte o resistor nas duas entradas abaixo da perna direita do sensor


Passo 5 :

Conecte o Jumper do GND a perna direita do resistor

Passo 6 :

Conecte o Jumper do 5v à entrada logo acima da perna esquerda do resistor

Pronto!
O seu Arduíno Uno R3 está montado com o sensor LDR




!PASSO A PASSO PARA EXECUTAR!

PASSO 1 --- Faça o download e instalação do Node.js
LINK: https://nodejs.org/pt-br



PASSO 2 ---
acesse o repositório SolarVision no GitHub.
Clique em code, e copie o link que aparecer lá!
LINK DA CLONAGEM: https://github.com/SoIarVision/SolarVision.git



PASSO 3 ---
Acesse o Terminal do cliente e dê os seguintes comandos
Git clone “link copiado do code”



Faça as modificações necessárias para o código se adequar ao ambiente do cliente, conferindo se está tudo de acordo e se está tudo em funcionamento.





PASSO 4 ---
Dentro do Terminal do cliente dê “npm I" para instalar a atualização da api, se certificando que esta tudo instalado siga para o proximo passo.




PASSO 5 ---
Após a instalação da API, no mesmo terminal escreva “npm start” e aparecer isso, significa que o servidor estar rodando certo sem nenhuma interrupção.
